游戏、UI 与交互设计作品集。包含精选项目、交互作品目录、影像与广告作品、个人荣誉及完整简历。

## 网站

https://15848918150ysl-cmyk.github.io/portfolio/

## 发布

纯静态网站，无需安装依赖。GitHub Pages 发布来源设为 GitHub Actions，推送 main 后自动发布。

## 文件

- `index.html`：页面与内容
- `style.css`：响应式布局与动效
- `script.js`：作品、目录、视频与奖状交互
- `assets/`：网站实际使用的图片、视频、奖状和文档

上线版布老虎视频已压缩为 H.264，原始视频保留在本地素材目录。
